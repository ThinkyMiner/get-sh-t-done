# Voice Guidelines

Preferred voice:
- direct
- confident
- compact
- technically credible

Avoid:
- generic AI hype
- buzzword stacking
- long introductions
- apologetic language
- screen-by-screen narration unless requested

Use:
- short punchy sentences
- clear contrast between old way and new way
- one memorable line about leverage or programmability

Good framing patterns:
- "If a human can repeatedly do it on a screen, it should become programmable."
- "The value is not one automation. The value is turning repeated work into infrastructure."
- "This is a 10x productivity lever because the same task stops being manual across people, teams, and time."

When using the team name:
- mention it once strongly
- optionally bring it back in the close
- do not force the wordplay every paragraph

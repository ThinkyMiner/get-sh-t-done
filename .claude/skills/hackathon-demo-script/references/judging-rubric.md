# Judging Rubric

Optimize answers for these themes:

## Impact
- broad reach
- repeatable value
- reusable across teams and workflows

## Problem statement quality
- clear pain
- concrete friction
- why current process does not scale

## Solution completeness
- cover the full flow, not only model generation
- mention capture, understanding, workflow generation, execution, and output

## Solution robustness
- stress real-world execution constraints
- mention auth, delayed UI, frames, popups, validation, and logs where relevant

## Skilled solution
- explain technical judgment, not just model usage
- emphasize why the system needed skills, structured correction, and execution logic

Demo-video guidance:
- problem first
- proof / why now
- live or credible demo
- impact close

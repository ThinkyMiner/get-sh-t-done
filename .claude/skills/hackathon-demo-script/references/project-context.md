# Project Context

Project name:
- Get Shit Done

Core product idea:
- Convert repeatable desktop workflows into reusable APIs by learning them from screen recordings and executing them reliably across real applications.

What the product currently does:
- accepts a screen recording
- extracts keyframes
- infers a workflow timeline
- generates structured steps
- applies skill-based correction for known workflow families
- executes the workflow through a browser runner
- exposes outputs through API endpoints
- keeps logs and screenshots for traceability

Strongest technical differentiators:
- two-stage timeline-to-workflow generation
- skill folders that encode reusable domain knowledge
- frame-aware and popup-aware browser execution
- ability to recover from weak generic model output using canonical skill guidance

Best honest product framing:
- This is not just video understanding.
- This is a system for turning repeated UI work into programmable infrastructure.

Hackathon theme fit:
- 10x productivity
- reduce repeated clicking, context switching, and manual data passing
- one repeatable workflow can become an internal capability used by many people or tools

Team roles:

- Kartik: Engineer, pipeline and architecture
- Vijay: Engineer, execution and reliability

Tone guidance:
- sound sharp and practical
- avoid hype that cannot be defended
- emphasize leverage, reuse, and scale
